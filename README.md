# 我爱说人话

> 那位大佬能拯救一下，搞了半天回复的能力还是拉垮

在 [x.com](https://x.com) 上帮你写**说人话的中文回复**：一次给几条候选，你挑一条，复制或填入回复框，**发送键永远在你手上**。

Chrome / Edge 扩展 · Manifest V3 · 原生 JS 无构建 · v2.16.0

> **只起草，不代发。** 没有任何自动发送路径。
> 唯一会在你账号上真实执行的动作是「回复后自动点赞原帖」，**默认开启但可随时关**，且只在你手动点了发送之后触发。
> 提示词和过滤规则来自 **152 条真实差评**的统计，不是拍脑袋写的。

---

## 为什么做这个

AI 写的评论一眼假：客套开场、排比三连、动不动总结升华、句句「不是 A 而是 B」。这个扩展不追求"更会写"，只追求**像一个人刷到帖子后随手打的一句话**。

- **踩雷硬过滤** —— 从 152 条真实差评里统计出的确定性规则：括号引号 `「」()`、破折号省略号分号、`首先/其次/总之/值得注意的是/赋能/落地/闭环/家人们/学到了`、「不是A而是B」句式、超 50 字、说教式开头，命中就丢弃。为保证交付条数不少，会多要 1 条再筛。
- **仿写评论区** —— 把这条帖子下面别人已发的回复当**仿写样本**喂给模型：学它们的语气、口语程度和切入角度。它们是已经发出去、被这条帖子接纳了的回复，等于告诉你"在这条帖子下面什么样的话是搭的"。**回复对象始终是原帖作者**，不会去接评论里的话。
- **提问式评论自动剔除** —— 别人向楼主提的问题（"5万是税前还是税后？"）是最强的诱饵，实测喂进去会有 **33% 的草稿跑去解答那个问题**。这类评论参考价值近乎为零，直接不给模型。加上这条后跑偏率降到 **0%**。
- **仿写有优先级** —— 接住原帖一个具体的点 > 仿写；20 字最好、50 字封顶 > 仿写。所以参考里全是「可惜了」「唉」这种空话时，不会把你带空泛（实测落地率 98% vs 96%，基本无差）。
- **配图直接看图** —— 纯图片帖不再放弃，切到视觉模型读图。实测一张 600px 图约 400 token。
- **流式生成** —— 首条候选约 **170ms** 就能复制，不用等全部生成完（非流式要等约 930ms）。
- **模型是实测选的** —— 下拉框里每个模型都标了实测延迟和 token，包括哪两个不建议用、为什么。默认 `qwen-flash`（711ms / 176 token）。`qwen3.x` 系列默认在偷偷跑思考模式，同一请求要 7–50 秒，这里自动关掉，延迟降 74–96%。
- **草稿箱** —— 每条草稿独立 `复制` / `填入` / `♥赞` / `✎备注` / `✕删除`；历史草稿按帖子折叠存档，离开原帖页也能翻回来复制。
- **备注不花钱** —— 觉得哪条不对，写一句「太客套」「没接住原帖」，纯本地保存，攒着的备注会自动变成下次生成的约束。要 AI 按备注重写是另一个显式按钮，会标明这一步花额度。
- **互动追踪** —— 用户名旁挂徽章显示「你回TA几次 / TA回你几次」，绿=双向、蓝=只有你回、橙=只有TA回。五个数据来源，共用一套去重键，重复看到同一次互动只算一次。
- **手速预估** —— 按你最近的实际发送速度，折算每小时、全天能回多少条。只统计真实点击发送的时刻，所以一次灌进上千条历史数据也不会污染。
- **未回关高亮** —— 在 `/following` 标出没回关你的人，在 `/followers` 标出你还没回关的人。
- **界面汉化** —— 只替换整段命中词典的可见文本节点，不改 `aria-label`（那会破坏可访问性、被 React 覆盖，还和未回关判断打架）。
- **诊断页** —— 把插件在当前页面真实看到的东西全列出来：账号怎么认出来的、本页几条推文、每条推文的所有链接、通知容器命中几个、输入框结构清单、存储占用与配额百分比。可一键复制报告。

## 安装

从源码加载，无需构建。

```bash
git clone https://github.com/changxi1303/wo-ai-shuo-ren-hua.git
```

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择项目目录
4. 点扩展图标，填 API Key、选模型，点 **测试连接**，然后 **保存**
5. 刷新 x.com 标签页

> 右下角会出现一个 **`话`** 字悬浮球，点它打开面板；可以拖动，位置会记住。
>
> **升级注意**：改动 `manifest.json` 或新增文件（如 `intercept.js`）后，必须在 `chrome://extensions` 点 **重新加载**，只刷新页面不够。

## 配置

支持任何 OpenAI 兼容的 `chat/completions` 接口。默认对接阿里百炼（DashScope）。

| 配置项 | 说明 |
| --- | --- |
| API Key | 明文存在浏览器 `chrome.storage.local`，只通过扩展后台发往你填的服务商 |
| Base URL | 必须是 `https`。换成其他服务商时保存会自动申请该域名权限，否则请求会被 CORS 拦 |
| 模型 | 下拉分组并标注实测数据；也可选「自定义…」手填。点「测试连接」后会把账号可用模型合并进下拉 |
| 看图模型 | 帖子带配图时自动切换。默认 `qwen3.5-omni-flash`（实测 507ms） |
| 配图清晰度 | `small`≈600px/401 token（默认）· `medium`≈1200px/1480 token。图片 token 与分辨率成正比 |
| 每次候选条数 | 1–5，默认 3 |
| 回复风格 | 简短直给 / 有观点 / 友好接话 / 轻松幽默 / 提问引导 |
| 随机度 / max_tokens | 默认 0.8 / 400 |
| 系统提示词 | 可整体编辑，也可一键恢复默认 |
| 踩雷硬过滤 | 默认开。关掉则原样返回模型输出 |
| 仿写评论区 | 默认开，最多带 20 条，单条截断 200 字 |
| 自动下滑加载评论 | 默认关。开启会在生成前临时滚动页面加载更多评论，加载完自动滚回 |
| 进帖自动生成 | **默认开**。每打开一条帖子就消耗一次 API 额度，不想要请关 |
| 自动填入首条 | 默认关 |
| 回复后自动点赞 | **默认开**。基准延迟 700ms ±40%（实际 420–980ms 随机），已在自己账号上真实执行点赞 |
| 互动追踪 / 我的用户名 | 自动识别失败时可手填 handle（不带 @） |
| 自动下滑扫描 | 最多轮数默认 40，每轮间隔默认 900ms |

## 使用

**生成回复**：推文工具栏上多了一个 **AI** 按钮，点一下出候选；或者打开悬浮球面板，在草稿箱页点「生成 N 条回复草稿」。流式生成时按钮上会显示已到达条数。

**草稿箱**：每条草稿一张卡片。

- `复制` —— 主按钮，走 `navigator.clipboard`，失败自动回退 `execCommand`
- `填入` —— 写进下方回复框，**不发送**。四级回退（`execCommand insertText` → paste 事件 → input 事件序列 → 直接写 DOM），每级都校验是否真写进去了；全部失败会自动改成复制到剪贴板
- `♥` —— 手动赞一下原帖
- `✎ 备注` —— 快捷标签 + 自由输入，**纯本地保存不花额度**
- `✕` —— 删除

**互动数据**：顶部显示当前认到的账号和识别方式。「立即扫描本页」只处理已加载的内容；「继续下滑扫描」会边滚边记（X 用虚拟列表，滚过去的节点会被卸载，所以必须边走边记），扫完**停在原地**，再点一次接着往下，不回头重扫。

**诊断**：出问题时先看这一页。它会把插件真实看到的东西列出来，而不是让你猜。

## 工作原理

```
intercept.js   MAIN world / document_start   被动观察 X 自己发的 GraphQL 响应
      │        提取 in_reply_to_status_id_str / in_reply_to_user_id_str /
      │        in_reply_to_screen_name / user_id_str，postMessage 给隔离世界
      ▼
content.js     隔离世界 / document_idle       主逻辑 + Shadow DOM 面板
      │        chrome.runtime.connect 长连接收流式增量
      ▼
background.js  Service Worker                 唯一网络出口（content script 直接
               经典 SW + importScripts        fetch 第三方 API 会被 CORS 拦死）
      ▼
defaults.js    三端共享的默认配置与提示词
```

**为什么需要 `intercept.js`**：X 在 `/with_replies` 上渲染你的回复时，DOM 里既没有「回复 @xxx」那一行，也没有指向被回复者的链接（实测：一条推文只有 5 个 `<a>`，全部指向你自己）。渲染层根本没带回复关系，任何选择器都挖不出来。但 X 自己的接口响应里每条推文都带 `in_reply_to_*` 字段 —— 权威、结构化、不随界面改版变化。

它只是**被动观察页面自己发出的请求**：不额外发任何请求，不读取、不存储、不转发任何凭据，用 `res.clone()` 读所以不干扰页面自己消费 body。

**去重键**：`你回TA` 用 `p:<父帖ID>`，`TA回你` 用 `r:<对方回复ID>`。五个数据来源（推文的回复行 / 点发送的瞬间 / 对话模块配对 / 我的帖子详情页 / 通知页）共用这套键，所以同一次互动被多路看到只算一次。

**踩雷硬过滤**在后台做，规则见 `background.js` 的 `auditItem`。

## 隐私

- **权限最小化**：只申请 `storage` 和 `clipboardWrite`。`host_permissions` 只声明 `x.com` / `twitter.com` / `dashscope.aliyuncs.com`；换其他服务商走 `optional_host_permissions` **按需弹窗申请**，不预先要全站权限。
- **API Key 明文存在本机** `chrome.storage.local`，扩展没有能力加密它。仅通过后台发往你自己填的服务商地址。**公用电脑请用完清空**。导出功能不含 Key。
- **草稿、备注、互动数据全部存在本机**，按账号分区（换号不串数据），可导出可导入。上限：60 帖 × 12 条草稿、5000 个追踪对象、8000 条 userId 映射，超限自动按 LRU 淘汰。
- **配额可见**：诊断页显示当前占用与配额百分比；写满时会先淘汰最久没互动的数据再重试，并明确提示，**不会静默丢数据**。
- **不代发**：没有自动发送路径。「填入」只写输入框，发送键在你手上。
- **会真实执行的动作只有一个**：回复后自动点赞原帖（默认开，可关）。点赞延迟随机化（700ms ±40%），固定间隔的机械节奏比延迟本身更容易被识别成自动化。

## 项目结构

```
manifest.json     MV3 声明，两组 content_scripts（MAIN world + 隔离世界）
intercept.js      MAIN world，被动提取 X 接口响应里的回复关系
defaults.js       三端共享：默认配置、提示词、模型分组、容量上限、数据迁移
background.js     Service Worker：唯一网络出口、候选解析、踩雷硬过滤、错误分类
content.js        主逻辑：草稿箱、互动追踪、诊断、Shadow DOM 面板
content.css       注入页面 DOM 的样式（徽章 / 标签 / AI 按钮）
popup.html/js     设置页
icons/            16 / 48 / 128
```

面板和 toast 走 Shadow DOM，与 X 的样式完全隔离，互不污染。

## 已知限制

- **依赖 X 的 DOM 结构**，改版可能失效。诊断页会把真实结构打出来（每条推文的所有 `<a>`、通知容器命中数、输入框清单），复制报告即可定位。
- **互动数据是被动累积的**：X 只渲染已加载的内容，你没刷到的就不会被记录。用「继续下滑扫描」补历史。
- **账号识别**依赖左侧导航头像链接等四处特征，窄屏或改版时可能失败 —— 这时在设置里手填「我的用户名」即可。
- **自动点赞**依赖 `[data-testid="like"]`，X 改版可能失效；失败会如实报告而不是静默。
- **无自动更新**，从源码加载，需要手动 `git pull` + 重新加载扩展。
- **MV3 Service Worker 空闲 30 秒会被回收**，冷启动有几百毫秒开销。已在进入帖子详情页和悬停悬浮球时预热。
- 视觉模型需要服务商开通对应产品；未开通时会给出可操作的错误提示。
